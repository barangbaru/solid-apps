Aman & Terproteksi (Read-Only Source)
Proses migrasi ini **hanya membaca (SELECT)** database Redmine asal. Sistem dijamin tidak akan merubah, menulis, atau menghapus data apa pun pada server database Redmine Anda.
Koneksi Database Redmine (MySQL)
Panduan & Alur Kerja
  1. Pastikan port database MySQL server Redmine Anda dapat diakses dari server Hive (buka firewall jika diperlukan).
  2. User database MySQL minimal harus memiliki permission **SELECT** pada database Redmine.
  3. Sistem akan mencocokkan user Redmine dengan karyawan Hive menggunakan email. Pastikan data email karyawan di **TalentCore** sudah terisi.
  4. Nomor issue/tiket Redmine akan disimpan pada nomor issue di Hive dengan format `RM-[id]` untuk mempermudah pelacakan dokumen.
